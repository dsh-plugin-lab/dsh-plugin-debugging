# locale/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

locale/ 特有约束：

- 两份文件是**成对件**，任何改动同批改；只改一份会留下一门语言没有展示元数据。
- 这里只放展示元数据（标题与描述），别处只留指针；能力说明、流程、规则一律不进这个 JSON。
- 面向用户的文案写该门语言；代码注释仍写中文（[../src/AGENTS.md](../src/AGENTS.md) 的分工不变）。
- 键集合由红线钉住：增删键要同批改断言，不许让 JSON 自由长字段。
- 不写「有哪些键 / 什么时候生效」，那是 [README.md](README.md) 的职责。
