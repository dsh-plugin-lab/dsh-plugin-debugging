# .agents/notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

notes/ 特有约束：

- 每篇第 3 行是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 必须跟指针行；`已归档` / `已否决` 必须跟一句话理由。
- 归档**就地标记**，不建 `archived/` 子目录：失效笔记保留原位置，只改状态行。
- 决策类（面对岔路口挑了一个）强制写 `## 替代方案`：不记录被打败的选项，下次必被重诉。命名 `YYYY-MM-DD-<主题>`。
- 依据类（做调查、对照、得出结论）替代方案可选；有下游决策时写 `## 支撑的决策` 指回去，不复制决策内容。
- 已实施的决策用**现在时**描述已落地的事实；事实性变化（路径、默认值、机制名）就地更新，决策反转才另写一篇并交叉引用。
- 不建索引文件，不逐篇列清单；不写「记录怎么组织、去哪查」，那是 [README.md](README.md) 的职责。
