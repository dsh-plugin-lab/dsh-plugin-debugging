# 决策：`dsh_sign_cookie` 交付的是**定位符**，不是「签成了」这句话

**日期**：2026-11-09 ｜ 状态：生效

## 问题

它原先只报「签成了、绑在哪个 authority、cookie 叫什么名」，值**刻意不进返回值**
（理由正确：`audit` 会被 spill 到磁盘，凭证进 `audit` = 凭证落盘）。而描述又写着
`Use after a 401, when a script or CLI client needs to authenticate` —— 于是它**承诺了一个
交付不出来的用途**。

真机上发生的（一次会话的完整轨迹，逐条可核对）：

| # | 动作 | 结果 |
|---|---|---|
| ① | 想验证真实页面里的一个 CSS 问题，需要会话 cookie | 调 `dsh_sign_cookie` |
| ② | 工具回复「签成了；值不返回，人或有本地脚本直接调签名器」 | **手上仍然没有可用的东西** |
| ③ | 去读宿主安装树的 `dsh-client-connection/lib/index.js` | 拿到 cookie 的算法形状 |
| ④ | 读 `$DSH_HOME/.credentials.yaml` | **根签名密钥进了会话上下文** |
| ⑤ | 自己写 `mkcookie.mjs` | 重造了一个签名器 |

⚠️ 关键点：护栏守住了「工具自己的输出里没有秘密」，却被**绕开**了 —— 而绕开的路把
**根密钥**（比它想避免的派生 cookie 重一个量级）送进了上下文。这是本仓「假绿三兄弟」的
同一族：判据全绿，真实行为是泄密。

第二处同源缺口：技能正文当时把配方**印全了**（`dsh-auth-<base64url(sha256(…))>`、
`v1.<body>.<sig>`、payload 四个字段），并明说「这就是你交给人的东西」。工具不交值、
正文教怎么造 ⇒ **正文成了第二个交付面**。

## 决策

**拒绝交付一个值，必须同时给出许可路径。** 具体形态：

- `name=value`（`Cookie:` 头那一段，恰好一行）写进
  `$DSH_HOME/<包名>/cookies/<cookie 名>.cookie`，**只回路径**（`key.cookieFile`）。
- 文件名是 authority 的函数 ⇒ 同一 authority 永远覆盖同一路径（幂等、无需协议、无需清理）；
  端口一变就是另一个文件，旧文件自然失效。
- 写盘走**宿主 `fs` 服务**（与 `dsh_restart` 同一个端口、同一个沙箱档位字面量
  `HOST_DATA_SANDBOX_MODE`），本仓不 import `node:fs` 的写 API（B10 的来源判据与路径无关）。
- **写不出去就是没签成**：结构化失败，绝不退回「干脆把值给模型」。降级路径必须是失败，不是泄密。
- 描述按四段骨架重新分配：**机制只进代价段**（`cost`），`what` 仍是能力本身，
  `boundary` 是承重句「值不在这个结果里，但你拿到了一个定位符」。成功路径**不给 `nextStep`**
  —— 动作已经做完，硬编一步就是「裸结论伪装成下一步」。
- 技能正文**删掉整段配方**，改成「拿 `cookieFile`，里面是一行 `name=value`」。配方的唯一
  home 留在 `src/lib/cookie-sign.ts` 文件头（给实现者，不给模型）。

判据：红线 **B33**（三格：写端口真被调用过 + 正文无配方记号 + 路径首段逐字等于包名）。

## 替代方案

- **保留「只报签成了」**：已由真机证伪 —— 它不阻止模型拿凭证，只把路径推向更坏的那条（读根密钥）。
- **直接返回 `Set-Cookie` / cookie 值**：能解决问题，但值进会话日志；且与「不返回」的既有纪律正面冲突，
  会把一份**没有有效期之外的约束**的凭证铺在 transcript 里。文件把「不进通道」与「真的能用」同时满足了。
- **走 `presentationMeta` 人通道**：需要客户端半边（已评估不做），而模型侧照样拿不到 ——
  对「脚本要用凭证」零帮助。
- **单独发一个签名器 CLI**：每次消费多一次 spawn，且 `files` 清单与 `check:release` 都要跟着扩；
  更关键的是**结构性保证会退回成纪律约束** —— 模型只要自己跑一次 CLI 就把值看见了。
- **写进 `spillStore`**：它给的 locator 是**不透明句柄**，脚本无法当路径读；且它随进程清扫
  （不跨重启）。凭证需要一个**可预期、能猜、能复读**的路径。

## 影响

- **代价**：本仓第一个**会落盘**的派生工具。落点在本包命名空间内，且根密钥本来就在同一目录、
  同一 ACL 下 —— 磁盘侧的攻击面上限不变；而会话记录侧的风险归零。
  沙箱档位要显式提档（与 `dsh_restart` 同一档、同一字面量来源）。
- **收益**：模型永远不必知道「怎么签」。它拿到一个路径，交给自己的脚本即可 ——
  「值不进通道」与「调用方真的能用」第一次同时成立。
- **连带**：`RESTART_SANDBOX_MODE` 改名 `HOST_DATA_SANDBOX_MODE`（三个写者共用一处字面量）；
  `lib/restart-fs.ts` 从「重启的 IO 端口」变成「写本包命名空间的唯一端口」（名字暂时保留，
  改名是独立的机械重构，不影响语义）。
