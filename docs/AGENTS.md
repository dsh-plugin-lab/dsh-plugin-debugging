# docs/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

docs/ 特有约束：

- 四份活文档各有**互斥职责**，每份开头都自述「本文负责 / 不负责」；那行声明就是分层契约，改职责要同批改那行与根 [../AGENTS.md](../AGENTS.md) 的文档地图。
- 引用宿主行为必须带真源或实测标记，并注明是哪一份宿主、什么版本；无标记的段落**不许当结论用**。
- 不把会漂的值抄进文档：宿主版本号、行号、计数、案例日期一律现查，写「形状」不写「值」。
- 宿主事实的真源集中在宿主契约台账，其余文档只引用结论、不重述证据（一处一事实）。
- 「宿主侧已核 / 未核」与「我们自己的取舍」分开写：前者进台账，后者进架构说明。
- 事故复盘、迁移 / 升级说明这类独立体裁按需新建目录，不塞进现有四份；不写「每份文档写什么」，那是 [README.md](README.md) 的职责。
