# skills/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

test/skills/ 特有约束：

- 三个 fail-closed 分支（缺文件、frontmatter 坏、正文空）**只能靠夹具触发**，真技能正文不可能坏成那样；改动注册路径必须同时补夹具，否则该分支变成空转。
- 夹具用注入口指过去，不许改生产路径解析（技能根是按产物位置算出来的）。
- 动态 scope 注册的断言必须覆盖「停用即解开」：只验注册成功会漏掉泄漏，而泄漏的表现是同一时刻老会话赢、新会话退回用户级。
- `agent/created` 的处理器不许 `await`，相关用例也必须走同步路径。
- 夹具目录不建双件、不进文档网络；不写「覆盖了什么 / 怎么跑」，那是 [README.md](README.md) 的职责。
