# scripts/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

括号里的编号指 [../AGENTS.md](../AGENTS.md) 的活跃坑。

scripts/ 特有约束：

- 这里是**只读检查**的落点：不写产物、不改工作树，判据红了就退出非零，由调用方决定怎么办。
- 每条判据都要写清**在哪个运行上下文里成立**。同一个 `import` 在解包目录里恒假，在能解析 peer 包的上下文里才为真；上下文写不清的判据只会给假红或假绿（坑 24）。
- 判据同形、内容各自表述：与工作区其他仓的同名脚本互不抄，改一份不影响另一份。
- 「发布态该有什么」是断言集合的**唯一 home**；文档讲流程与判例，两边互补、不互相抄。
- 门禁身份件（格式化忽略清单等）不在本目录，但与本目录的跑法耦合：给忽略清单加一行会让身份件比对报不一致（坑 5）。
- 不写「有什么脚本 / 什么时候跑」，那是 [README.md](README.md) 的职责。
